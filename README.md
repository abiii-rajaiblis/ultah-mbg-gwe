# Desi Ayulia — 24th Birthday Coquette Website ♡

Website scrapbook ulang tahun yang terinspirasi dari desain referensi:
- palet pink coquette / dusty pink
- typography serif + handwritten script
- polaroid, filmstrip, vinyl record, lace/checker pattern
- responsive untuk mobile
- animasi reveal saat scroll
- tombol musik
- birthday wish modal + confetti

## Cara menjalankan
Cukup buka `index.html` di browser.

## Tambahkan musik
Masukkan file musik milikmu sendiri ke:
`assets/music.mp3`

Lalu tombol Music akan memainkan musik tersebut.

## Ganti foto
Di `index.html`, elemen bertuliskan `PHOTO 01` sampai `PHOTO 05` dapat diganti dengan:
`<img src="assets/foto1.jpg" alt="...">`

Simpan foto di folder `assets/`.

Tidak membutuhkan database atau server.
